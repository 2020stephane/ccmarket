(inner) logError(error, contextopt, extraopt, sourceopt) → {void}

Enregistre une erreur dans `errors.json` et l'affiche dans la console. Chaque entrée contient la date, l'heure, le contexte, le message, le type d'erreur, le stack trace nettoyé, et des données additionnelles libres.
Parameters:
Name Type Attributes Default Description
error Error | unknown L'erreur à journaliser (instance d'`Error` ou toute autre valeur).
context string <optional>
 "inconnu" Contexte de l'erreur, ex. `"chargement config"`, `"appel API"`.
extra Object <optional>
 {} Données libres additionnelles : `userId`, `url`, etc.
source string <optional>
 "backend" Origine de l'erreur : `"backend"` ou `"frontend"`.
