(inner, constant) db :mysql2/promise.Pool

Pool de connexions MySQL (interface promises de `mysql2`), configuré à partir des variables d'environnement `DB_HOST`, `DB_USER`, `DB_PASSWORD`, `DB_NAME` et `DB_PORT`. En cas d'échec de création du pool, l'erreur est journalisée via `logError` puis relancée, ce qui interrompt le démarrage du serveur.
