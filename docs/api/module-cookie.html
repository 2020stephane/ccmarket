Supprime le cookie d'authentification `monToken`, avec les mêmes options que celles utilisées lors de sa création (nécessaire pour que la suppression soit bien prise en compte par le navigateur).

Génère un JWT signé pour un utilisateur donné et le dépose dans un cookie `monToken` sécurisé (`httpOnly`, `sameSite: strict`, `secure` en production).
